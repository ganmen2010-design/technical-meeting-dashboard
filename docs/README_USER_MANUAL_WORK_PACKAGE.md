### 3. 三大核心主模組操作指南

儀表板採用**現代極簡雙層導覽架構**，起始畫面僅顯示 3 大主頁籤與待命引導卡，點選或雙擊主頁籤即可瞬間展開各模組內容。

#### 📌 模組 1：公告與指引中心 (`data-tab="announcements"`)
- **1.1 每月技術會議行程表 (Google 日曆 5 欄工作日模式)**：
  - 自動過濾非技術會議行程，**僅呈現各工區技術會議排程**。
  - 排除週六、週日，以週一至週五 5 欄工作日清晰呈現。
  - 支援月份切換（上個月/下個月/今天）、自訂顏色標記 6 大工程處。
  - 支援「**匯出日曆檔 (.ics)**」一鍵匯入 Outlook / Google Calendar，並可直達「**在 Google 日曆中開啟**」。
- **1.2 每月技術會議運作概況 (一頁式全量下拉視圖)**：
  - **4 大關鍵 KPI 指標**：納管專案工地數、累計追蹤待辦筆數、歷次會議技術議題庫、全公司待辦完成率。
  - **動態基準日連動引擎**：自選統計基準日後點擊「更新計算數據」，系統即時全量重算。
  - **工處與工地績效雙欄併排**：
    - **P12 各工處執行績效**（扣除後續辦理、排名與燈號分析）。
    - **P11 各工地執行績效**（待辦件數、完成率與成果檢附率）。
  - **P13 全工區技術議題管控項目覆蓋率分析**與 **P10 各工處場次統計**完整對齊。
- **1.3 發布技術指引 (`00發布區`)**：
  - 直通 NAS `2.技術會議運作指引(供查看及下載)\00發布區`。
  - 支援資料夾樹狀結構檢視、手風琴預設收合模式與右上角「全部展開 / 全部收合」。

#### 📌 模組 2：各專案作業區 (`data-tab="workspaces"`)
納管全台 **9 大技術會議重點專案工地**（新光合纖南港、公西檔案庫房、台南崇明商場、朴子安居、坤門安居、平實安居、立行倉儲、中油綠能、CDC 防疫中心）。

點擊專案卡片「**進入作業區**」，彈出抽屜視窗，內含四大專業頁籤：

1. **歷次會議資料 (簡報與紀錄)**：
   - **預設為收合模式**，畫面簡潔整齊。
   - 點擊任一場會議標題即可展開該場檔案；右上角提供「**全部展開 / 收合**」批次切換按鈕。
   - 提供「**查看/開啟**」（線上預覽）、「**複製路徑**」（一鍵複製 NAS 實體路徑）與「**下載**」三合一按鈕。
2. **技術議題管控表 (多維篩選 + CRUD 寫入 + CSV 匯出 + NAS 同步)**：
   - **全量排定項目 (172 筆) 預設展示**：完整列出各項次，不遺漏任何排定項目。
   - **頂部多狀態 KPI 篩選列**：
     - 📋 `全部排定項目`
     - ⏳ `基準日前應辦`（連動表首統計基準日）
     - 🟢 `已完成`
     - 🔵 `進行中 (檢討中)`
     - 🟠 `未排負責人`
     - 🔴 `成果未填`
   - **多維組合篩選**：支援階段 (Stage)、類別 (Category)、狀態 (Status) 複合下拉選單。
   - **快速搜尋框**：支援中文/注音輸入法（IME composition）保護，即時關鍵字檢索不卡頓。
   - **CRUD 編輯與持久化**：點擊「新增管控項目」或表格列「編輯」按鈕，可彈窗編輯所有欄位，修改即時寫入本機 `localStorage`，重新整理或重開機皆永久保存；若連線內部伺服器則自動寫入後端 JSON 資料庫。
   - **匯出管控表**：一鍵將包含所有最新修改的管控表匯出為 UTF-8 CSV / Excel 檔案。
   - **同步 NAS 最新版**：隨時一鍵清除本機暫存並與 NAS 最新版檔案完整同步。
3. **圖說契約進度表**：即時點閱最新版圖說審查與進度管控檔。
4. **專案待辦事項 (含「進行中」按鈕與多狀態篩選)**：
   - 表首 KPI 列完整包含：`待辦完成率`、`全部待辦`、`已完成`、`後續辦理`、`成果未填`、`進行中`。
   - 點擊任一按鈕即可**局部即時過濾**下方表格，高光標示選中狀態。

### 5. 常見問題與排除指引 (Troubleshooting & FAQs)

| 問題狀況 | 可能原因 | 建議排除方式 |
| :--- | :--- | :--- |
| **頁面提示「載入資料失敗」** | 未連上企業內部網路或未讀取到 JSON | 1. 檢查是否連上公司 VPN 或 NAS 網路。<br>2. 確認 `public/data/nas_data.json` 檔案是否存在。 |
| **點擊複製路徑後檔案開不起來** | 該電腦未掛載 `\\192.168.1.221\s5` 權限 | 開啟檔案總管，輸入 `\\192.168.1.221\s5` 並輸入個人網域帳密授權一次即可。 |
| **在儀表修改管控表時，NAS 檔案需要開啟嗎？** | 不用開啟 | 系統具備獨立儲存機制，修改自動保存在瀏覽器本機 `localStorage`，無需開啟 NAS 上的 Excel。 |
| **檢索工項時引述內容是否符合專業工法？** | 知識庫匹配模組 | 系統內建鋼板樁、鋼軌樁、中間樁、地錨、連續壁、防水等專屬工程知識矩陣，自動精準匹配。 |
| **瀏覽器一直顯示舊版本版面** | 瀏覽器快取 (Cache) 暫存 | 按 `Ctrl + F5` 進行強制重新整理（URL 已內建 `?v=50.0` 版本號防止快取）。 |
| **忘記自訂密碼** | 個人自訂密碼遺失 | 使用統一初始帳號 `FU@fengyu.com.tw` / `Aa34561297+b` 登入，再點擊「修改為個人帳密」重新設定。 |
